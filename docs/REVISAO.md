# Roteiro para revisão independente

Estado: **pendente**. Os testes automatizados foram executados no ambiente de desenvolvimento; isso não é uma revisão externa.

1. Baixar o projeto sem receber instruções além do README.
2. Registrar sistema operacional, versão de Python/SQLite e comando usado.
3. Executar os testes e a demonstração em um diretório novo.
4. Conferir `evidence/minha-execucao.json`: pedido cancelado v3, três efeitos, entrega repetida classificada como duplicata.
5. Confirmar no teste de reinício que um processo novo abre o mesmo banco.
6. Propor uma falha adicional e registrar a expectativa de negócio.
7. Registrar dificuldade, defeito ou divergência com passos para reprodução.

Não incluir dados privados. Só publicar nome, empresa ou comentário da pessoa revisora após permissão específica. Não transformar resultado local em alegação de desempenho, homologação ou impacto financeiro.
